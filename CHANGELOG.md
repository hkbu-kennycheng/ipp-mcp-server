# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-12
### Added
- Project initialization and FastMCP core server setup.
- mDNS printer discovery module using zeroconf.
- Thread-safe PrinterRegistry for multi-printer profile management.
- Built-in MCP tools: `list_printers`, `get_printer`, `register_printer`.
- Comprehensive unit test suite and GitHub Actions CI workflow.
